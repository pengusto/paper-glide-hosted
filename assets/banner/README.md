# Paper Glide banner artwork

These dark/light illustrations were created on 23 October 2026 with OpenAI's built-in image generation/editing tool at the maintainer's request. The maintainer-provided Pengusto profile banner supplied the penguin character reference; it was not a template for the city scene. The light image was edited from the project artwork to preserve the same character and overall scene.

The banner depicts a paper airplane, scissors and falling stones. It is an editorial illustration, not a screenshot, a new game build or evidence of tested gameplay. The actual gameplay recording remains separately credited in the root README. No private project code or Revival assets were used.

The final revision replaces glowing collectibles on the flight trail with stones at staggered heights and vertical motion strokes above them, following the maintainer's correction that the stones should appear to fall. Keep the images in sync when editing the scene. Earlier local drafts were retained outside the repository.
